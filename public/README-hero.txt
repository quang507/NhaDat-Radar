ĐẶT ẢNH HERO Ở ĐÂY
===================

1. Đổi tên ảnh cover thương hiệu của bạn thành: hero.jpg
   (hoặc hero.png / hero.webp)
2. Trên GitHub: mở thư mục public này -> Add file -> Upload files
   -> kéo hero.jpg vào -> Commit changes.
3. Vercel tự deploy, banner hero hiện ngay trên trang chủ.

Khuyến nghị: nén ảnh xuống dưới ~500KB để tải nhanh
(dùng tinypng.com hoặc squoosh.app). Kích thước đẹp: ~2000x750px.

Có thể xoá file này sau khi đã upload hero.jpg.
